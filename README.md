# Baguio Barangay Dengue Surveillance & Hotspot Monitoring System

## 1. Overview
The **Baguio Barangay Dengue Surveillance & Hotspot Monitoring System** is an interactive epidemiological analysis toolkit and command-line application (CLI) written in R. It processes community-level dengue surveillance data across Baguio City barangays to compute morbidity metrics, classify outbreak risk tiers, analyze age and sex demographics, monitor annual and weekly peak trends, and generate reproducible hotspot reports.

---

## 2. Requirements
- **R Runtime Environment**: R (version 4.0.0 or higher recommended).
- **Core Packages**: Base R libraries (`base`, `stats`, `utils` — no third-party package compilation required).
- **Automated Setup Script**:
  - Windows users can run `install_requirements.bat` located inside each subfolder to automatically detect or download and install the R runtime environment.

---

## 3. How to Run
To launch the interactive terminal menu:

### Via Batch Launcher (Windows)
Double-click `run_terminal.bat` or run:
```cmd
run_terminal.bat
```

### Via Direct Command Line
Navigate to the desired folder (`With Comments/` or `Without Comments/`) and execute:
```bash
Rscript terminal_menu.R
```

To execute the automated batch report generator and export hotspot summary data directly:
```bash
Rscript surveillance_analysis.R
```

## 4. Files & Structure

| Filename | Role & Description |
| :--- | :--- |
| `terminal_menu.R` | Interactive console application (CLI) providing overview statistics, hotspot rankings, barangay lookup, demographic breakdowns, trend charts, and CSV exporting. |
| `surveillance_analysis.R` | Standalone batch reporting script that processes raw surveillance data and outputs the hotspot summary CSV. |
| `hotspot_utils.R` | Reusable analytics module containing `RISK_CONFIG` threshold configurations and the `calculate_barangay_hotspots()` metric aggregation engine. |
| `run_terminal.bat` | Automated batch launcher that resolves `Rscript.exe` from standard paths/registry and executes `terminal_menu.R`. |
| `install_requirements.bat` | Environment verification and installer script for automatic R runtime setup. |
| `datasets/baguio_dengue_surveillance_synthetic.csv` | Primary case-level surveillance dataset containing epidemiological records. |
| `datasets/baguio_barangays_geo.csv` | Geographic and demographic reference table with barangay coordinates, districts, and estimated populations. |
| `datasets/baguio_dengue_hotspot_summary.csv` | Aggregated hotspot report generated by the analysis pipeline. |

## 5. Data Dictionary (`baguio_dengue_surveillance_synthetic.csv`)

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| `case_id` | String | Unique synthetic identifier for each reported dengue case (e.g., `BGO-DNG-00001`). |
| `date_onset` | String (YYYY-MM-DD) | Date of symptom onset recorded for the patient. |
| `morbidity_year` | Integer | Epidemiological reporting year (e.g., `2024`). |
| `morbidity_week` | Integer | Epidemiological calendar week of morbidity (1–53). |
| `barangay` | String | Name of the Baguio City barangay where the case was reported. |
| `age` | Integer | Patient age in years. |
| `sex` | String | Biological sex of patient (`M` for Male, `F` for Female). |
| `clinical_classification` | String | Clinical severity tier (`Severe Dengue`, `Dengue with Warning Signs`, `Dengue without Warning Signs`). |
| `outcome` | String | Patient clinical outcome (`Active`, `Recovered`, `Died`). |

## 6. Risk Tier Definitions

Hotspot severity is classified based on cumulative cases and attack rates (incidence per 10,000 population) as defined in `RISK_CONFIG`:

| Risk Tier | Criteria & Thresholds | Public Health Action Description |
| :--- | :--- | :--- |
| **HIGH (EPIDEMIC)** | `Total Cases >= 200` **OR** `Attack Rate >= 150 per 10k` | Urgent outbreak response, vector eradication, hospital surge preparation, and active community screening. |
| **ALERT (ELEVATED)** | `Total Cases >= 80` **OR** `Attack Rate >= 80 per 10k` | Heightened entomological surveillance, targeted fogging/misting, and community clean-up drives. |
| **CONTROLLED** | Below alert thresholds (`Cases < 80` and `Attack Rate < 80 per 10k`) | Baseline vector control, routine monitoring, and public health education. |
